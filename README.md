# 🧮 BMI Calculator

A simple Python command-line application that calculates **Body Mass Index (BMI)** based on the user's weight and height and displays the corresponding BMI category.

## ✨ Features

* Accepts weight in kilograms
* Accepts height in meters
* Calculates BMI
* Displays BMI up to 2 decimal places
* Classifies BMI into different categories
* Includes basic input validation

## 🛠️ Technologies Used

* Python
* `input()`
* Arithmetic operators
* `if-elif-else`
* Exception handling

## 📐 BMI Formula

```text
BMI = Weight (kg) / Height² (m)
```

## 📊 BMI Categories

| BMI Range      | Category    |
| -------------- | ----------- |
| Below 18.5     | Underweight |
| 18.5 – 24.9    | Normal      |
| 25.0 – 29.9    | Overweight  |
| 30.0 and above | Obese       |

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/Nirliptasethy/bmi-calculator.git
```

Open the project folder:

```bash
cd bmi-calculator
```

Run the program:

```bash
python bmi_calculator.py
```
